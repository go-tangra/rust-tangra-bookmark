# bookmark join bundle

Generated by the gateway (Gateway operations › Modules › bookmark › Add).

    docker compose up -d

The bundle runs bookmark with its own PostgreSQL (TLS, certificate from the
bundle's local CA). `init-db.sh` creates the application role
`bookmark_app` (`NOBYPASSRLS`) on the database's first start;
`bookmark-bootstrap` applies the schema as the owner. Only the mesh ports
(9975 gRPC, 9976 HTTP) are published, on the IP you gave.

`private/` holds credentials (the single-use enrolment token, the bundle's
TLS keys); `.env` holds the generated database passwords. Keep them on this
host only, and back up the `bookmark-db` volume. After the first start the
module renews its identity itself (`/state/svid.json`).

The module needs no event bus. To show `bookmark.shared` notifications, give
it a Valkey user `bookmark` on the core's event bus (see the comment in
`config.yaml`).

Importing the v3 bookmark service's data: the help page *Import v3
bookmarks* (`bookmark-migrate`, in the image).
